# 漫游 · Manyou

**把散落的照片，重新看成生活。**

漫游是一款面向 macOS 的本地照片浏览工具。它从你选择的文件夹中建立只读索引，把分散在桌面文件夹、外接硬盘等位置的照片与视频汇集到一个安静的视觉空间。

## 设计原则

- **原地读取**：不移动、重命名或删除源文件。
- **本地优先**：索引与偏好设置保存在 Mac 本地，不上传照片。
- **沿用已有分类**：选中的根文件夹下，每个子文件夹自然成为一个浏览入口。
- **不增加整理压力**：不做待整理清单，不要求用户补标签。
- **照片优先**：以摄影墙为主要界面，尽量减少多余装饰。

## V0.1 范围

- 选择一个或多个本地根文件夹。
- 递归扫描常见图片与视频格式，包括 JPG、PNG、HEIC、WebP、TIFF、GIF、MOV、MP4、M4V。
- 按原文件夹浏览，并提供全部照片视图。
- 按文件修改时间排序；EXIF / QuickTime 拍摄时间解析将在后续完善。
- 支持的图片生成缩略图；视频以视频标记卡片显示，原文件可从 Finder 打开。
- 收藏照片、搜索文件名、重新扫描已选文件夹。
- SQLite 保存文件索引与收藏；绝不对原始文件执行写入或删除操作。

## 数据与安全

V0.1 以文件路径作为本地索引键；原文件移动或外接盘离线时会标记为不可用。请勿把个人照片、数据库、缩略图缓存或硬盘内容提交到 GitHub。

## 开发状态

当前是早期工程原型。真实文件系统访问、SQLite 持久化和缩略图生成必须在 macOS 上验证；GitHub 前端构建通过不代表所有桌面能力已验证。

## 开发

需要 Node.js、Rust 与 macOS Xcode Command Line Tools。

```bash
npm install
npm run tauri dev
```
